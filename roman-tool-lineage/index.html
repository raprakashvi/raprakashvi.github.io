Aspect ratio is the existing principal-frame length/width ratio. Solidity is segmented area / convex-hull area. A high aspect ratio indicates elongation. Solidity depends on silhouette segmentation, pose, and open handles. Proximity here is descriptive and is not the multiblock shape-distance score. Similarity does not establish function or ancestry.

Scope & limitations

A traceable working collection

The core atlas contains curated historical witnesses, catalog objects, grouped artifacts, images and book-history records. These are different units of evidence. A record count is not a count of unique physical tools, inventions or evolutionary events.

What is documented?

Source descriptions and historical terminology are preserved. Automated tool labels and analyst interpretations appear separately from documented function. Undocumented function remains unknown. Reviewed descriptions and model predictions are reserved for future work.

Delivery status

Phase acceptance and remaining tasks. Human review is deferred while source-grounded enrichment and exploratory analysis continue.

Museum expansion

Pitt Rivers now includes a bounded crawl of public editorial accession entries. Its modern catalog remains under maintenance. Smithsonian Anthropology records come from small official API queries for knives, scrapers and tweezers. These samples are not complete museum imports. Access and image rights

This collection uses a basic interface gate. All static files, JSON exports and images remain publicly retrievable. Noindex discourages indexing; it cannot prevent discovery. Existing images are displayed for research with source credits retained. Display does not establish redistribution or model-training eligibility, which require separate review.
